📖 How to Use (pose → reference numbering)

  • Click any card to add / remove it from the reference list — the badge shows its @imgN number
  • Order in the right panel = input order = the model's image_1, image_2 … slots (use ↑↓ to reorder)
  • "📋 Copy prompt snippet" copies an English prompt snippet with the numbered image order
  • "📤 Upload & wire image_1..N" uploads selected poses to ComfyUI and wires them to the reference slots, then auto-runs
  • "🚀 Write prompt & run" writes the snippet to the enhancer node's user_requirement, pushes to Show Text, triggers preview, and closes
  • Switch to "Compare" view to compare all 5 camera angles of one pose side by side
  • Filter by pose group / camera view / number range / keyword
  • The selection is saved locally (browser + plugin folder) and survives closing the page
